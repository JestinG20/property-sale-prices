# 🏙️ Advanced Machine Learning Models for Predicting Property Sale Prices in New York City

This project aims to build and evaluate advanced machine learning models for predicting property sale prices in New York City using a real-world dataset. The models explore various preprocessing techniques, feature engineering methods, and ensemble approaches to improve prediction accuracy.

## 📊 Project Overview

Real estate markets, especially in a dynamic city like New York, are influenced by a wide range of variables. This project uses publicly available property sales data to:

- Clean and preprocess real estate data
- Perform feature engineering to extract meaningful insights
- Train and compare various machine learning models
- Evaluate the models using appropriate metrics
- Identify the most important features driving sale prices
  
## 🧠 Machine Learning Models Used

The following models were implemented and compared:

- **Linear Regression**
- **Ridge and Lasso Regression**
- **Random Forest Regressor**
- **Gradient Boosting Machines (XGBoost, LightGBM)**
- **Support Vector Regression**
- **Ensemble Methods**

## 📈 Evaluation Metrics

The models were evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

Cross-validation was applied to ensure the generalizability of the models.

## 🔍 Key Findings

- Feature selection and encoding techniques significantly affected model performance.
- Ensemble methods like XGBoost and Random Forest provided the best accuracy.
- Geographic and building-related features were among the top predictors of price.
